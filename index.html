📱 TẠO MOBILECONFIG

Upload thư mục web → Tool tự tạo file .mobileconfig → Cài app ngoài Home Screen
💡 Cách dùng:
1. Upload thư mục web (có index.html, app.js, img/...)
2. Điền tên app, URL host, icon
3. Nhấn BẮT ĐẦU TẠO
4. Tải file .mobileconfig về → cài vào iPhone
📁 CHỌN THƯ MỤC WEB
⚙️ THÔNG TIN APP
Xem trước icon
Từ URL ở trên
Sẵn sàng — Chọn thư mục web
📖 HƯỚNG DẪN CÀI
1. Tải file .mobileconfig về máy
2. Mở file → iPhone hiện thông báo cài profile
3. Vào Settings → Profile Downloaded → Install
4. Nhập mật khẩu iPhone → Install → Install
5. Icon app xuất hiện ngoài Home Screen ✅

⚠️ iOS 16.4+ có thể chặn cài profile ngoài. Nếu vậy:
• Bật Developer Mode (Settings → Privacy → Developer Mode)
• Hoặc dùng Apple Configurator trên Mac/PC
• Hoặc dùng Add to Home Screen từ Safari (đơn giản hơn)
