WEBCLIP ĐA ICON

Tạo config nhiều icon, 2 chế độ tải
1. Chọn số WebClip cần tạo
2. Nhập nội dung hiển thị
3. Chọn icon từ máy (hoặc URL)
4. Nhấn TẠO CONFIG → chọn CÀI NGAY hoặc LƯU TỆP
SỐ WEBCLIP CẦN CÀI 2 icon
NỘI DUNG WEBCLIP
Nếu tạo nhiều icon, tên sẽ thành: Thông tin 1, Thông tin 2...

Nhấn "CÀI NGAY" → iPhone mở Settings → Install → Xong

1. Nhấn "LƯU TỆP" → tải file về máy

3. Cài như bình thường
