WEBCLIP ĐA ICON

Tạo config nhiều icon — chỉ dùng URL ảnh https
1. Chọn số WebClip cần tạo
2. Nhập nội dung hiển thị
3. Nhập URL ảnh icon (https) — KHÔNG dùng file upload
4. Nhấn TẠO CONFIG → CÀI NGAY hoặc LƯU TỆP
SỐ WEBCLIP CẦN CÀI 2 icon
NỘI DUNG WEBCLIP
Lưu ý: iOS không chấp nhận icon dạng file upload. Phải là link https.
Cách lấy link: Upload ảnh lên imgur.com → chuột phải → Copy image address → dán vào ô trên.
Nếu để trống → icon dùng mặc định của iOS.

CẤU HÌNH PROFILE
Lưu ý: Khi bật "Không cho xoá", user không thể xoá app/config. Muốn gỡ phải cài file mới không có khoá.
