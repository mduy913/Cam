📖 HƯỚNG DẪN CÀI
1. Tải file .mobileconfig
2. Mở file → iPhone báo "Profile Downloaded"
3. Settings → Profile Downloaded → Install
4. Nhập mật khẩu → Install → Install
5. Nhiều icon app xuất hiện ngoài Home Screen ✅
