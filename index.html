✅ LINK VĨNH VIỄN:
Đã tự copy vào clipboard. Gửi link cho người khác để họ cài!
HƯỚNG DẪN CÀI
📲 CÀI NGAY:
Safari → Nhấn "CÀI NGAY" → Settings mở → Install

📤 CHIA SẺ FILE:
Chrome → Nhấn "CHIA SẺ FILE" → Save to Files → Mở Files → Cài

📤 UPLOAD FILE:
1. Nhấn "UPLOAD FILE" → đợi 5-15s
2. Link tự copy vào clipboard
3. Gửi link cho người khác
4. Họ mở link → tải file .mobileconfig
5. Cài vào iPhone
