📱 WEBCLIP TỰ DO

Nhập nội dung bất kỳ → Tạo config → Cài vào iPhone thấy nội dung
💡 Cách dùng:
1. Nhập tên app + nội dung HTML hiển thị
2. Nhấn TẠO CONFIG
3. Tải file .mobileconfig → cài vào iPhone
4. Nhấn icon ngoài Home Screen → thấy nội dung
📝 NỘI DUNG WEBCLIP
👁️ XEM TRƯỚC NỘI DUNG
💻 HTML ĐẦY ĐỦ (sẽ nhúng vào config)
⚙️ CẤU HÌNH PROFILE
⚠️ Lưu ý: Khi bật "Không cho xoá", user không thể xoá app/config qua Settings. Muốn gỡ phải cài file mới không có khoá.
Sẵn sàng
📖 HƯỚNG DẪN CÀI
1. Tải file .mobileconfig
2. Mở file → iPhone báo "Profile Downloaded"
3. Settings → Profile Downloaded → Install
4. Nhập mật khẩu → Install → Install
5. Icon app xuất hiện ngoài Home Screen ✅
6. Nhấn icon → thấy nội dung bạn đã nhập
